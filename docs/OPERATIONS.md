# Operations (local single-node profile)
**Start / stop:** `python -m veylstream serve` (Ctrl-C stops; processors are joined and log files closed). **First run:** `python -m veylstream setup-demo [--no-seed]`. Config via environment (see `.env.example`).
**Health:** `/api/v1/health/live`, `/api/v1/health/ready` (checks DB); per-component status in the UI *Pipelines* page / `GET /pipeline/status`, derived from real checks (DB query, log lag, processor thread, last error, producer heartbeats, dead letters, failed deliveries).
**Migrations:** applied automatically and idempotently on start (`schema_migrations`). Add new `(version, sql)` entries to `store.MIGRATIONS`; never edit applied ones.
**Backup / restore:** stop the server (or accept a point-in-time copy), then copy `VEYLSTREAM_DATA_DIR` (`veylstream.sqlite`, `-wal`, `-shm`, `broker/`, `datasets/`). SQLite online backup (`sqlite3 db ".backup file"`) works while running; copy `broker/` after it. Restore = put the files back and start. *Restore was not drill-tested.*
**Retention:** hourly job deletes live events/dead letters older than `retention_days` (default 3) and windows older than 2× that; replay/experiment data is kept. The log directory is truncated segment-wise behind the checkpoint. There is no archival export.
**Logs:** Flask/werkzeug logs to stderr; unhandled errors are logged with the request id and returned as `internal_error` without detail. No secrets are logged (API keys are only shown once in the creation response). Logs are not JSON-structured.
**Credential rotation:** admin → *Data sources → Rotate key* (old key dies immediately) or `POST /sources/<id>/rotate`; sessions: `POST /auth/logout`; to invalidate all sessions `DELETE FROM sessions`.
**Replay:** analyst → *Historical replay*; speed 0 = as fast as possible; max 2 concurrent. Jobs are in-process threads: a server restart marks nothing as resumed (a running job is lost; its row stays `running`; re-run it).
**Common failures:** `503 backpressure` → processor paused/behind (check *Pipelines*, resume); `429` → raise source `rate_limit_per_s`; many `late_event` dead letters → clock skew or backfill: raise `allowed_lateness_s`; webhook `failed: non-public address` → intended SSRF block, set `VEYLSTREAM_ALLOW_PRIVATE_WEBHOOKS=1` only on trusted networks.
**Run behind TLS:** the built-in server speaks plain HTTP and is a development server (Werkzeug). Put a reverse proxy with TLS in front; do not expose it directly.
